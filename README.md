Space Invaders Android Game (Kotlin, Jetpack Compose)

• Developed a fully functional 2D Space Invaders game for Android using Kotlin and Jetpack Compose, featuring real-time gameplay mechanics and responsive touch controls.

• Designed and implemented a custom game engine responsible for game loop execution, player movement, enemy spawning, projectile handling, collision detection, and score tracking.

• Applied MVVM architecture with ViewModel-based state management to maintain game state, synchronize UI updates, and improve code maintainability.

• Built a custom GameCanvas and on-screen control system, enabling smooth rendering, efficient game-object updates, and an engaging mobile gaming experience.
